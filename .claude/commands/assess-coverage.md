Read CLAUDE.md. Record or revise evidence for one product and business unit.

Run `npm run accounts -- assess-coverage --code= --account= --unit= --product= --status= --evidence= --assessed-on= [--competitor=] [--potential=] --actor=`. Flags use `--name=value`; quote values containing spaces. Add `--json` for structured results. Substitute the operator's actual values and omit optional brackets. Never run literal placeholders.

Read the affected account or stakeholder before a mutation. Record the actual operator in --actor. If a name is ambiguous, show the candidates and ask which record they mean. Present findings with the account, owner, date and next action. Unknown evidence stays unknown. Planning estimates are not booked revenue; keep currencies separate.
