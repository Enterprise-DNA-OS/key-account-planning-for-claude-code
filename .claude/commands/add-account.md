Read CLAUDE.md. Open an owned account plan with its objective and review date.

Run `npm run accounts -- add-account --code= --name= --owner= --currency= --objective= --review-due= --actor=`. Flags use `--name=value`; quote values containing spaces. Add `--json` for structured results. Substitute the operator's actual values and omit optional brackets. Never run literal placeholders.

Read the affected account or stakeholder before a mutation. Record the actual operator in --actor. If a name is ambiguous, show the candidates and ask which record they mean. Present findings with the account, owner, date and next action. Unknown evidence stays unknown. Planning estimates are not booked revenue; keep currencies separate.
